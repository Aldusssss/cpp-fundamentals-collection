# cpp-fundamentals-collection

**Exercise Structure**

A collection of 23 C++ exercises solved for the Computer Science Fundamentals course at Politecnico di Milano. The exercises are organized in 6 macro-areas that follow the course progression, from loops and basic algorithms to linked lists, trees and classes. Each exercise is in its own folder (`es_01` to `es_23`) with the source file and, where needed, the input files.
